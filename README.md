## timeconv

### 概要

`timeconv` は、秒数を時間・分・秒に変換するLinuxコマンドです。

また、時間・分・秒を秒数に変換する逆変換にも対応しています。

### コンパイル方法

C言語のソースコードから実行ファイルを作成します。

```bash
gcc -Wall -Wextra -o timeconv timeconv.c
```

### 使用方法

#### 1. 秒数から時間・分・秒に変換

標準入力から秒数を入力します。

```bash
echo 3725 | ./timeconv
```

実行結果：

```text
1時間2分5秒
```

#### 2. 時間・分・秒から秒数に変換

`-r` オプションを指定し、「時間 分 秒」の順番で入力します。

```bash
echo "1 2 5" | ./timeconv -r
```

実行結果：

```text
3725
```

### 入力ルール

- 通常モードでは0以上の秒数を入力してください。
- 逆変換モードでは「時間 分 秒」の順番で入力してください。
- 分と秒は、それぞれ0以上59以下で入力してください。
- 不正な入力や負の数を入力した場合はエラーになります。

### テスト方法

次のコマンドでテストを実行できます。

```bash
bash test-timeconv.bash
```

すべてのテストに成功すると、`OK` と表示されます。
