## timeconv

### 概要
秒数を時間・分・秒に変換するLinuxコマンドです。
また、時間・分・秒を秒数に戻すこともできます。

### コンパイル方法
gcc -o timeconv timeconv.c

### 使用方法

#### 秒数から時間・分・秒に変換
echo 3725 | ./timeconv

実行結果：
1時間2分5秒

#### 時間・分・秒から秒数に変換
echo "1 2 5" | ./timeconv -r

実行結果：
3725

### 入力ルール
通常モードでは0以上の秒数を入力します。
逆変換モードでは「時間 分 秒」の順に入力します。
不正な入力や負の数を入力した場合はエラーになります。
